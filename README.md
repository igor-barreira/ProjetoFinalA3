# 💼 Sistema de Cadastro de Colaboradores

> Projeto desenvolvido para a disciplina de Algoritmos e Programação (A3)
> Curso: Análise e Desenvolvimento de Sistemas (ADS)
> Semestre: 2026-1

O sistema foi desenvolvido em Java com o objetivo de aplicar conceitos fundamentais de programação orientada a objetos, estruturas de decisão, estruturas de repetição, métodos, listas dinâmicas (ArrayList) e manipulação de dados por meio de classes e objetos.

## 📋 Funcionalidades

• Cadastro de colaboradores padrão
• Cadastro de colaboradores comissionados
• Cadastro de colaboradores de produção
• Validação de dados informados pelo usuário
• Cálculo de salário para colaboradores comissionados
• Cálculo de salário para colaboradores de produção
• Geração de folha de pagamento
• Exibição da quantidade total de colaboradores cadastrados
• Exibição detalhada das informações de cada colaborador

---

## 📋 Estrutura do Projeto

O projeto está dividido em diferentes classes para organizar as responsabilidades do sistema:

• A3.java: classe principal responsável pelo menu e controle da aplicação.
• ColaboradorPadrao.java: define os atributos dos colaboradores padrão.
• ColaboradorComissionado.java: define os atributos dos colaboradores comissionados e realiza o cálculo salarial baseado em comissão.
• ColaboradorProducao.java: define os atributos dos colaboradores de produção e realiza o cálculo salarial baseado na quantidade produzida.
• FolhaDePagamento.java: responsável pela exibição da folha de pagamento e das informações dos colaboradores cadastrados.
